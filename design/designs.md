## Set 1 · 2026-11-10 · picked Clean Moderno, built
Brief: MálagaMove is a transport price comparison app for locals and visitors in Málaga. It helps users find the cheapest ride by comparing estimated fares for Uber, Cabify, Bolt, and local taxis in real time. The home screen features an intuitive route input form followed by a sorted list of transparent price breakdowns.
